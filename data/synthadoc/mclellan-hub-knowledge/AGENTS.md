## Purpose

## Ingest Guidelines
- Create one clearly titled page for the source's primary subject
- Update an existing page only when the primary subject is the same specific person, project, document, event, or concept
- A shared organisation, product, keyword, or broad theme is not enough to merge pages
- Never append source material to Index, Wiki Overview, Wiki Purpose, Dashboard, McLellan Hub Overview, or Synthadoc Integration
- When uncertain whether material belongs in an existing page, create a dedicated page
- Preserve provenance for every source that creates or updates a page
- Use clear human titles, never filenames, URL fragments, "Watch", "Overview", or generic section headings
- Summarize key claims and findings without copying full transcripts unless explicitly useful
- Cross-reference related concepts using `[[page-name]]` link syntax
- Flag contradictions with ⚠ markers

## Organisation Guidelines
- Categories are optional and broad; prefer a few stable areas over detailed taxonomy
- Tags describe specific subjects, technologies, organisations, or projects
- Related links are navigation suggestions, not evidence that two subjects should be merged
- Keep source-specific operational briefs separate from general platform or system overview pages

## Query Guidelines
- Answer using only wiki content
- Always cite sources using `[[page-name]]` link syntax
- Separate established facts from gaps in the available record
